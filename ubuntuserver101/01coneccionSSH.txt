########################
### Conetcion to SSH ###
########################

Para conectarte a tu Ubuntu Server desde VS Code en Windows mediante 
SSH, sigue este paso a paso:


Paso 1: Instalar la extensión en VS Code

1. Abre Visual Studio Code en Windows.

2. Ve al panel de extensiones en la barra lateral izquierda 
   (o presiona Ctrl + Shift + X).

3. Busca Remote - SSH (de Microsoft) e instálala.


Paso 2: Iniciar la conexión SSH

1. En la esquina inferior izquierda de VS Code, 
   verás un botón azul pequeño con dos flechas (><) 
   o puedes presionar F1 (o Ctrl + Shift + P) para 
   abrir la paleta de comandos.

2. Escribe y selecciona:
   Remote-SSH: Connect to Host...

3. Elige la opción Add New SSH Host....

4. Escribe la cadena de conexión con el usuario de 
   tu servidor y la IP de la máquina (192.168.18.166):

Bash

ssh pretox@192.168.18.166

5. Selecciona el archivo de configuración donde guardarlo 
   (elige la primera opción recomendada: C:\Users\TU_USUARIO\.ssh\config).


Paso 3: Conectarte al servidor

1. Vuelve a hacer clic en el botón azul de la esquina inferior 
   izquierda (><) o pulsa F1 -> Remote-SSH: Connect to Host....

2. Verás listada la IP o el host 192.168.18.166; haz clic sobre él.

3. Se abrirá una ventana nueva de VS Code:

  - Te preguntará el tipo de sistema operativo: selecciona Linux.
  - Si te pregunta si confías en el host fingerprint, haz clic en Continue.
  - Te pedirá la contraseña de tu usuario de Ubuntu Server 
    (la que usas para hacer sudo). Ingrésala y presiona Enter.


Paso 4: Abrir tu repositorio y trabajar

   Una vez conectado (verás SSH: 192.168.18.166 en verde o azul en la esquina 
   inferior izquierda):

1. Ve a File -> Open Folder... (o pulsa Ctrl + K, Ctrl + O).

2. Te mostrará las rutas de tu servidor. Selecciona la carpeta donde clonaste tu repositorio:

   /home/pretox/IaC-Ubuntu-Server

3. Pulsa OK y vuelve a introducir tu contraseña si te la pide.

4. Abre la terminal integrada de VS Code presionando Ctrl + Ñ (o Ctrl + ~).


Paso 5: Cómo cerrar la conexión correctamente

 - Desde VS Code: Haz clic en el botón azul o verde de la esquina inferior 
   izquierda (SSH: 192.168.18.166) y selecciona Close Remote Connection 
   (o ve al menú superior: File $\rightarrow$ Close Remote Connection).

 - Desde la terminal integrada o CMD: Escribe exit o presiona Ctrl + D.
